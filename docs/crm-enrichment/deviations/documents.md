# Deviations: Documents (Phase 5 screen build)

Where the Documents screen (`/documents`, `Documents.dc.html`) departs from the design, and why. Same columns as
`DEVIATIONS.md`; the lead builder folds these in. The schema's own departures are V-P5-05..09 there.

| ID | Where | Design | Built | Reason |
|---|---|---|---|---|
| V-DOCUMENTS-01 | Documents list, «Stored in» | Google Drive, OneDrive, SharePoint | `documents.storage`; every document is on «Platform» | No drive is connected (DOC-03: `doc_storage_connect` answers `not_connected`); a document is stored on the platform until a drive adapter copies it |
| V-DOCUMENTS-02 | Documents list, seeded rows | Six documents: Opened, Awaiting signature, Sent, Draft, Signed, Opened (uploaded) | Five documents from the design's templates on its deals, rendered by the database: the warehouse quote opened three times through a link to Kari; the others drafts | «Awaiting signature» and «Signed» need a PDF (no PDF worker) and sent invitations (no email provider); «Sent» needs a document without missing values, and d104 has no products for `[product.table]`. Never fabricate (D-41) |
| V-DOCUMENTS-03 | Documents list, «Uploaded: Kundens innkjøpsvilkår.pdf» | An uploaded PDF row | Not seeded; no upload control | `document_upload` records a file an edge function has stored under the deal; that function does not exist, so no file can exist. An uploaded row renders as «Uploaded PDF» when one does |
| V-DOCUMENTS-04 | Status pills | Five statuses | The five, plus Declined, Expired and Revoked in the design's own pill colours | D-41: the states the schema has (spec §2) |
| V-DOCUMENTS-05 | Preview, header | Orgpuls mark; «Tilbud T-101 · 5. oktober 2026» | The deal's product as the brand (Orgpuls' mark for Orgpuls; the product's colour tile and name for the others); the document number from the template's prefix counter (`T-1`) and its creation date in the template's language | Q12: documents carry the brand of `deals.product`, and the bundle has a mark for Orgpuls only. The number is `number_prefix` + a per-prefix sequence; the word «Tilbud» is the document's own text |
| V-DOCUMENTS-06 | Preview, body | A fixed layout: «Tilbud til …», «Til … · orgnr · gyldig til 19. oktober», two hard-coded lines (or value/12), «Sum eks. mva / Mva 25 % / Totalt» | The document's rendered body (`body_html`) in the design's preview styles: the template's text with merge values, the product table the database built from `deal_items` (labels in the template's language, amounts as «39,00 NOK», V-P5-07), then per month, one-off, total contract value ex. VAT, VAT per rate and total incl. VAT | Spec §2 and Q13: the lines are the deal's items, VAT follows each line's rate, and the contract value row is the database's. «gyldig til» is `valid_until` (creation date + the template's validity days) |
| V-DOCUMENTS-07 | Preview, footer | «Product table filled from the deal · placeholders: [deal.title] [person.name] [organization.orgnr] [product.table]» | The template's own placeholders, and whether a PDF exists («No PDF yet: the PDF worker is not connected») | The placeholders are the tokens found in the body; the PDF state is the honest one (Q11) |
| V-DOCUMENTS-08 | Preview, missing values | — | A notice listing the missing values; they block sending, not creation | DOC-01; `merge_missing` |
| V-DOCUMENTS-09 | Trackable link, address | `docs.orgpuls.no/s/k7Qd101xZ2` (built from the deal id) | `go.owntheagenda.com/d/<token>` shown once, when «Copy link» makes it, with a note that the host does not serve links yet; afterwards `go.owntheagenda.com/d/…` with when and for whom it was made | D-28 and Q1: a random token returned once, only its SHA-256 stored. The host does not run yet |
| V-DOCUMENTS-10 | Trackable link, views | «Kari Nordmann · Oslo — Yesterday 18:40 · 4 min», «Unknown viewer · forwarded» | The link's recipient (or its label, or «Anyone with the link»), the time and the duration; link-scanner views are left out | No city (it would need the IP, D-37, §10) and no «forwarded» (it cannot be known without cookies or fingerprinting) |
| V-DOCUMENTS-11 | «Copy link» and «Revoke» | Toasts | «Copy link» copies the address known in this session, or makes a new link for the person the document is addressed to; «Revoke» closes the newest open link | Spec §2: a lost token is replaced by a new link; `document_link_revoke` takes one link |
| V-DOCUMENTS-12 | «＋ Document from template» | Toast «Document created from «Tilbud — standard» in Google Drive» | A dialog: template, deal, optional name, then `document_create`; the toast names «Platform storage»; missing values and unknown tokens are listed in the dialog | Spec §2; a document is created on the platform (a drive copy waits for the adapter). A drive template is refused as not connected |
| V-DOCUMENTS-13 | Templates, cards | «Sales team»; the design's order; two or three placeholder chips | The team's name («Sales Norway»); the database's order (category, then name); every distinct token of the body | `doc_templates_get`; `placeholders` are found by `app.doc_tokens` when a template is saved |
