# Deviations — Inbox (Phase 2 screen build)

Where the Inbox screen (`Inbox.dc.html`) departs from the design, and why. Same columns as `DEVIATIONS.md`;
the lead builder folds them in. No mailbox is connected (seeded history, no token), AI, WhatsApp, telephony,
the inbound mail route and the Gmail add-on do not exist: each shows its honest state (D-41).
