# Deviations — Insights (Phase 4 screen build)

Where the Insights screen departs from `design-reference/sentral/project/Insights.dc.html`, and why. Same
columns as `DEVIATIONS.md`; the lead folds them in. Database changes the screen would need are in
`docs/crm-enrichment/requests/insights.md`.

| ID | Where | Design | Built | Reason |
|---|---|---|---|---|
| V-INSIGHTS-01 | Header | «reports per user: unlimited (entitlement)» as text | «unlimited» or the number from the `count_limits` setting | ENT-02 limit (D-17); never a literal |
| V-INSIGHTS-02 | Dashboards › picker | Five fixed options, «Sales manager» selected | The dashboards `dashboards_get` returns (four role templates, own, shared), templates named in the staff member's language; opens the staff member's own dashboard, else the Default template; «My dashboard» is offered until the staff member has one and opens the empty state; `?dashboard=<id>` keeps the choice | Dashboards are rows (INS-03); D-41 for the empty dashboard |
| V-INSIGHTS-03 | Dashboards › tiles | Nine literal tiles with fixed charts and spans | The open dashboard's tiles, in its stored order and span, each the report run for the viewer by `dashboard_get`, drawn with the chart its definition names (the Default template draws owner as bar, stage as column, source as pie) | Tiles are data; the prototype's tile list is its own |
| V-INSIGHTS-04 | Dashboards › period | No period control | Each tile runs with its definition's period (`dashboard_get(p_period => null)`) and says which in its subtitle | The design draws no dashboard period; R-INSIGHTS-08 if one is wanted |
| V-INSIGHTS-05 | Tile «Deals per stage» | «New business · progress», five stages | The template's open deals by stage over every pipeline | The 0024 template has no pipeline filter (R-INSIGHTS-03) |
| V-INSIGHTS-06 | Tile «Stage conversion» | 72/58/49/61/68 % | Not on any template, so not rendered; the builder's Conversion type computes it from `deal_stage_history` («Qualified → Discovery call», share of deals that entered a stage and reached the next; the last stage → Won) | FAB; no template tile uses `report_conversion` (R-INSIGHTS-01) |
| V-INSIGHTS-07 | Tile «Won value» | «312 000 kr», «+18 %» | Sum of NOK deals won this quarter (`report_run`); the change against the previous quarter in percent; «Previous period: 0 kr» when that was zero | FAB |
| V-INSIGHTS-08 | Tile «Open pipeline» | «+6 %» | The open NOK total; the change against the pipeline snapshot 30 days ago, or «No pipeline snapshot from 30 days ago yet» | FAB; `pipeline_snapshots_daily` starts filling nightly with 0024 |
| V-INSIGHTS-09 | Tile «Average sales cycle» | «34 d», «−4 d» | Average days from created to won for deals won this quarter, the difference in days against the previous quarter (shorter is green); «—» when nothing was won | FAB |
| V-INSIGHTS-10 | Tile «Open value by owner» | Three hard-coded owners | Every owner with open deals, first names as the design writes them | FAB (fixed list) |
| V-INSIGHTS-11 | Tile «Lost reasons» | Price 9, Chose a competitor 6 … | Lost deals counted by their stored reason (the seed holds one) | FAB |
| V-INSIGHTS-12 | Tile «Activities completed» | Calls 64, Meetings 31, Tasks 88, Emails 142, Demos 12 | Done activities this month by activity type; «Email» counts logged email activities only | FAB; mail sync does not log activities yet |
| V-INSIGHTS-13 | Tile subtitles | Literals («Deals · performance», «Dimension: source field») | Built from the definition: record type · period (or «open now» / «all time») · «by» dimension | Never fabricate a description |
| V-INSIGHTS-14 | Limited visibility | — | Without Deals › See reports of others: every tile says «your records only», the builder says so under the preview, the deal forecast «your deals only» | Task: say whose data a limited tile shows (0024 counts own records) |
| V-INSIGHTS-15 | Arrange and resize, Share | Always available | Arrange for owners and editors, Share for owners; on a template or a dashboard shared as viewer both are disabled with the reason («A template is read-only · duplicate it …») | `dashboard_role`: templates are read-only for everyone |
| V-INSIGHTS-16 | Duplicate | Toast only | `dashboard_duplicate` copies the dashboard, its tiles and reports as «<name> (copy)» and opens the copy | Real action |
| V-INSIGHTS-17 | Share popover | Sales team / Ingrid / Ola, role selects without effect | The dashboard's shares (staff, team, visibility group) with Viewer/Editor/Remove, and «Share with …» to add one; «Not shared with anyone yet» when empty | `dashboard_shares` |
| V-INSIGHTS-18 | Builder › Report type | Five types | Performance, Conversion and Duration (deals); Progress and Products disabled «— not available yet» | `report_run` computes them as Performance (R-INSIGHTS-05) |
| V-INSIGHTS-19 | Share › Public live link | `sentral.orgpuls.no/d/pub_7Gx2kQ9…`, Revoke/Create | «Waits for the public host go.owntheagenda.com» and «Create link» disabled | D-28: public pages live on go.owntheagenda.com, which does not exist yet |
| V-INSIGHTS-20 | PNG · PDF | Toast «exported» | Disabled, «PNG and PDF need a renderer that does not exist yet» | No server-side renderer (task); 0024's comment about the browser's print is superseded by the task |
| V-INSIGHTS-21 | Builder › Filters | Three static strings | The definition's conditions, each removable, and «＋ Filter» (column, condition, value); OR within a field as «is one of» | Real filters (`app.filter_sql`); no OR across fields or «does not contain» (R-INSIGHTS-06) |
| V-INSIGHTS-22 | Builder › Entity | Campaigns, Projects, Revenue selectable | Shown disabled «— not available yet» | `report_check` accepts deals, activities, leads, people and organizations only |
| V-INSIGHTS-23 | Builder › Group by and Measure | «Competitor (custom)», «Board meeting month (custom)», «Average «Employees in scope» (custom)» | The record type's dimensions from `report_fields`, custom fields from the registry (none seeded, so none listed); measures Count, Sum/Average of value (deals, leads), Average of each numeric custom field, Weighted value (deals) | The registry is the whitelist (INS-07) |
| V-INSIGHTS-24 | Builder › preview | Competitor literals, scorecard «312 000 kr» «+12 %» | `report_run` of the definition; the scorecard's change against the previous period | FAB |
| V-INSIGHTS-25 | Builder › Period and Pipeline | Period list only | The period applies to the created date (the won date for Duration); Conversion adds a Pipeline select; Custom range adds From and To dates | The design names no date field; conversion needs a pipeline; a custom range needs its days |
| V-INSIGHTS-26 | Builder › Series colour | Input without effect | Kept in the definition (`color`) and used for the first series | Prototype placeholder |
| V-INSIGHTS-27 | Save to dashboard | Toast only | Saves the report (`report_save`) and a tile on the open dashboard when the staff member may change it, else on their own, else creates «My dashboard»; opens it | Real action |
| V-INSIGHTS-28 | Builder › segments | Not clickable | Clickable, opening the drill-down | The footnote's promise («click any segment …») |
| V-INSIGHTS-29 | Drill-down | `D.deals.filter((x,j)=>(j+i)%4===0)`; «Rows exported as XLSX» toast | The rows behind the segment (`report_drill`, audited); Export rows calls `report_export` (export right, audited) and downloads XLSX; titles open the record | FAB; INS-08 |
| V-INSIGHTS-30 | Template tile titles | — | English in bokmål for the four templates | Template report names are stored text (R-INSIGHTS-02) |
| V-INSIGHTS-31 | Goals | Five literal goals, no way to add one | `goals_get` (none seeded: «No goals yet»); «＋ Goal» and a goal dialog in the design's language; a goal opens for editing or deleting for its creator or with Deals › Manage pipelines | FAB; D-41 |
| V-INSIGHTS-32 | Goals › pace | «On pace» when 60 % reached | On pace when the share reached is at least the share of the interval gone; «No matching records yet in this period» at zero | INS-05 |
| V-INSIGHTS-33 | Forecast › deals | Oct–Jan hard-coded | The next four months from `forecast_deals`; an empty state when no open deal closes in them; a note counting open deals without a close date | The months are now's |
| V-INSIGHTS-34 | Forecast › products | `rec = 30 + 4.5i`, stepped installments | `forecast_products` for twelve months: subscription MRR carried forward plus recurring lines of won deals (Recurring), instalment lines (Installments); empty state when all are zero | FAB |
| V-INSIGHTS-35 | Ask for a report | Canned reply and definition (Stacked column …) | The unconfigured state: description and prompts editable, Generate, Refine, Open in builder and Save as is disabled, «AI is not configured yet …», «Nothing generated yet.» | AI gateway not configured (phase 7); never a canned answer |
| V-INSIGHTS-36 | 390 px | The prototype's 12-column grid and two-column builder squeeze to unreadable columns | Tiles stack at full width below 768 px; builder and Ask for a report stack; drill-down columns narrow | The design's 390 rendering is unusable |
| V-INSIGHTS-37 | Scorecard footnote | «vs previous period» always | «vs previous period» or «vs 30 days ago» with a change; «Previous period: <value>» when no percentage can be computed; «Nothing to compare in the previous period» when there is none | Never show a change that does not exist |
