# Deviations: Meetings (Phase 7 screen build)

Design: `design-reference/sentral/project/Meetings.dc.html`. Data spec: `docs/crm-enrichment/specs/projects-meetings.md` §2, §8.3.
Schema contract: `deviations/meetings-schema.md` (V-P7M-*). Nothing is connected: calendar, meeting bot, transcription, AI,
email provider and the file storage signer. Every action that needs one shows its not-connected state (D-41), and no
toast says something happened before the database answered.
