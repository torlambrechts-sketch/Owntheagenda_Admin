# Deviations: Mobile (Phase 8 screen build)

Route `/mobile` (`Mobile.dc.html`). Spec `docs/crm-enrichment/specs/platform-security-mobile.md` §7, §6 Q13, §8; contract
`docs/crm-enrichment/deviations/platform-schema.md` (Mobile). The screen is the live preview §6 Q13 recommends: the six
phones show the signed-in staff member's own data through the same RPCs the PWA will use (D-38), with three D-41 panels under
them (offline sync, push devices, notification types). Same columns as DEVIATIONS.md.
