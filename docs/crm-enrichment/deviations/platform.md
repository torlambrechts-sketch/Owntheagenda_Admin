# Deviations: Platform (Phase 8 screen build)

Routes `/applications` (Platform › Applications) and `/api` (Platform › API and integrations), design `Platform.dc.html`, data
spec `specs/platform-security-mobile.md` §1, contract `deviations/platform-schema.md` (0044). Same columns as `DEVIATIONS.md`;
the lead folds them in.
