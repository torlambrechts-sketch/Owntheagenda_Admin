# Deviations: Projects (Phase 6 screen build)

Where the Projects screen (`app/(admin)/projects`) departs from `design-reference/sentral/project/Projects.dc.html`, and why.
Data spec: `docs/crm-enrichment/specs/projects-meetings.md` §1; schema contract: `deviations/projects-schema.md` (V-P6P-*).
Database needs are in `requests/projects.md`. The lead folds these rows into `DEVIATIONS.md`.

| ID | Where | Design | Built | Reason |
|---|---|---|---|---|
| V-PROJECTS-01 | Toolbar hint | «Workflow «Won deal → project» creates projects automatically», always | Shown only while an active workflow has a `project_action` step `create_from_template`, with that workflow's name (`projects_board.workflow_hint`). The seeded «Won deal → project, invoice and Slack» stays a draft (Slack and accounting are not connected), so the hint is hidden | Never fabricate (precedent V-DEALS-15, spec §1.1) |
