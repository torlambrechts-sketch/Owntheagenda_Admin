# Deviations — Development, the delivery half (DevHub.dc.html and DevClaude.dc.html, v3, migration 0080)

Where the build differs from the drawing, and why. Views: Releases, Release gate, Integrations register, Code and
environments, Delivery metrics, Vercel and Supabase, Repo rules. The element-by-element sources are `../v3/dev-a-gap.md` and
`../v3/dev-b-gap.md`; `../v3/PLAN.md` and Tor's X-V3-1 override them: deploys come from Vercel's deployment webhooks, signed,
pushed to `dev-events` (no Vercel token, no GitHub); build facts come from a signed POST by the products' CI to `dev-events`;
Sentral holds no Supabase Management token for a product.
